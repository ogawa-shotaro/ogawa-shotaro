## 主な実績

### Clinical Agent Hub（AIハッカソン 優勝）

医師と患者の診察内容をAIで記録・構造化する、医療機関向けの文書作成支援プロダクトです。  
オンプレミス版をクラウド版として展開し、より多くの医療機関へ普及させることを目的としたプロジェクトに参画しました。

**主な機能**

- 診察中の会話の文字起こし（STT）
- 文字起こし内容のSOAP形式への構造化
- OCRによる薬剤情報の取り込み・転記、紹介状の取り込み

**担当範囲**

- アプリケーション開発からインフラ構築、本番ローンチまでを一貫して担当
- Amazon Bedrockを活用した生成AI機能の実装
- TerraformによるIaC化、GitHub ActionsによるCI/CDの構築

## 専門領域

- **インフラ（AWS）**：EC2・VPC、ECS・Fargate、Lambda・API Gateway、RDS・Auroraを用いた構成設計・構築、Amazon Bedrockを活用した生成AI機能の組み込み
- **IaC・CI/CD**：Terraform・AWS CDKによるインフラのコード化、GitHub Actionsによる自動化、Dockerによるコンテナ化
- **バックエンド**：Node.js（Express・NestJS）、LaravelによるAPI・アプリケーション開発
- **データベース・フロントエンド**：MySQL・PostgreSQL・DynamoDB、React
